# CONSTITUTION (Supreme and Immutable)

This document is the supreme normative framework for the pricing-service repository. All agents, contributors, and automated processes MUST comply. Conflicts are resolved in favor of this Constitution.

## 1. Architecture Principles
- **Hexagonal Architecture is mandatory.** `domain/` MUST remain pure (no Spring, JPA, or framework annotations/dependencies). `application/` defines ports and use cases; `infrastructure/` provides adapters/config only.
- **Dependency Rule:** Dependencies point inward (infrastructure → application → domain). Domain has zero outward dependencies.
- **Boundaries:** Ports in `application/port/` are contracts; implementations live in `application/service/` or adapters in `infrastructure/`.

## 2. API-First
- **Source of truth:** `src/main/resources/rest/openapi.yaml`. All REST contracts MUST be defined there first.
- **Generated code is sacred:** Controllers/interfaces/DTOs generated by `openapi-generator-maven-plugin` into `target/generated/openapi/` MUST NOT be manually edited. Regenerate via `./mvnw clean compile` after spec changes.

## 3. Data & Time
- **UTC everywhere:** Prices stored as `TIMESTAMP WITH TIME ZONE`, processed as `java.time.Instant` UTC. API queries MUST be normalized to UTC.
- **Determinism:** On equal max priority, selection MUST return the first record encountered in the retrieved collection (documented behavior).

## 4. Persistence
- **Schema management:** Liquibase is the only mechanism for schema/migrations/seeds (`src/main/resources/db/changelog/`). `spring.jpa.hibernate.ddl-auto=none`. `spring.jpa.open-in-view=false`.

## 5. Testing Discipline
- **Tagging:** Use `@Tag("unit")`, `@Tag("repository")`, `@Tag("e2e")` appropriately. Unit = pure, no Spring context; repository = `@DataJpaTest`; e2e = full `@SpringBootTest` with RestAssured.
- **Verification:** Prefer focused runs (`-Dgroups`, `-Dtest`) before full suite.

## 6. Immutability & Amendment
- **Supreme:** This Constitution supersedes README notes, conventions, or agent preferences.
- **Immutable:** This file SHALL NOT be modified by agents unless explicitly and unanimously instructed by the human owner with written justification. Violations are not permitted.
